# Structure Gel — Load Massive Dungeons and Portals

Structure Gel 9minecraft Mod provides the background code needed to run popular dimension and structure mods. It acts as a helpful toolset that other mods use to build massive dungeons, custom portals, and new worlds. You do not need this mod unless another mod tells you to download it. It runs quietly in the background to make sure everything loads correctly.

Acts as a required file for mods like Blue Skies to work properly.

## What this build is

An unofficial rebuild of **Silver_David**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
